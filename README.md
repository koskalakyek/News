# News Agent — خلاصه خودکار اخبار در تلگرام

این پروژه هر ساعت اجرا می‌شود، فیدهای RSS منابع معتبر را در سه حوزه
**Finance**، **Edge of Science** و **International Trade** بررسی می‌کند،
مهم‌ترین اخبار جدید را با Claude خلاصه و فیلتر می‌کند (به فارسی) و همراه
لینک اصلی به تلگرام شما ارسال می‌کند.

---

## مرحله ۱: ساخت ربات تلگرام (Telegram Bot)

1. در تلگرام وارد چت با **@BotFather** شوید.
2. دستور `/newbot` را بفرستید.
3. یک اسم دلخواه برای ربات انتخاب کنید (مثلاً `My News Agent`).
4. یک username دلخواه که به `bot` ختم می‌شود انتخاب کنید (مثلاً `my_news_agent_bot`).
5. BotFather یک **توکن** به شما می‌دهد، شبیه این:
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   این را جایی امن ذخیره کنید — این همان `TELEGRAM_BOT_TOKEN` است.

## مرحله ۲: پیدا کردن Chat ID خودتان

1. به ربات ساخته‌شده خودتان در تلگرام پیام دهید (مثلاً بنویسید `سلام`).
   (باید یک بار پیام بفرستید تا ربات بتواند بعداً به شما پیام بدهد.)
2. در مرورگر این آدرس را باز کنید (به‌جای `<TOKEN>` توکن خودتان را بگذارید):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. در خروجی JSON دنبال `"chat":{"id":XXXXXXXXX` بگردید. آن عدد همان
   `TELEGRAM_CHAT_ID` شماست.

## مرحله ۳: گرفتن Gemini API Key (رایگان)

1. وارد [aistudio.google.com/apikey](https://aistudio.google.com/apikey) شوید
   (با حساب گوگل خودتان — نیازی به کارت اعتباری نیست).
2. روی **Create API Key** کلیک کنید.
3. کلید ساخته‌شده را کپی کنید — این همان `GEMINI_API_KEY` است.
4. سهمیه رایگان مدل `gemini-2.5-flash` برای این پروژه (فقط ۱ درخواست در
   ساعت) بیش از کافی است.

## مرحله ۴: ساخت مخزن (Repository) در گیت‌هاب

1. یک ریپازیتوری جدید (می‌تواند Private باشد) در GitHub بسازید.
2. تمام فایل‌های این پروژه (`main.py`, `requirements.txt`, `seen_links.json`,
   پوشه `.github/workflows/`) را در آن آپلود/پوش کنید.

## مرحله ۵: اضافه کردن Secrets

در ریپازیتوری خودتان بروید به:
`Settings → Secrets and variables → Actions → New repository secret`

سه secret زیر را اضافه کنید:

| نام | مقدار |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات از مرحله ۱ |
| `TELEGRAM_CHAT_ID` | آی‌دی چت از مرحله ۲ |
| `GEMINI_API_KEY` | کلید API از مرحله ۳ |

## مرحله ۶: فعال‌سازی

- به تب **Actions** ریپازیتوری بروید، workflow با نام `Hourly News Agent`
  را پیدا کنید و روی **Run workflow** کلیک کنید تا یک بار دستی تست شود.
- اگر همه‌چیز درست باشد، پیام خلاصه در تلگرام دریافت می‌کنید.
- از این پس، طبق تنظیم `cron: "0 * * * *"` هر ساعت به‌صورت خودکار اجرا می‌شود.

---

## نکات مهم درباره دقت و صحت

- برای جلوگیری از تکرار خبرها، لینک هر خبر ارسال‌شده در `seen_links.json`
  ذخیره می‌شود و این فایل بعد از هر اجرا خودکار commit می‌شود.
- این نسخه از **Gemini API** (رایگان، مدل `gemini-2.5-flash`) برای
  خلاصه‌سازی استفاده می‌کند. سهمیه رایگان آن (حدود ۲۵۰ درخواست در روز)
  برای اجرای هر ساعت (۲۴ درخواست در روز) کاملاً کافی است.
- به مدل به‌صراحت دستور داده شده که **فقط** از خبرهای موجود در فید
  استفاده کند و هیچ لینک یا خبر جدیدی نسازد (برای جلوگیری از "توهم" یا
  hallucination).
- منابعی مثل **Bloomberg**، یادداشت‌های **Ray Dalio**، **WTO** و
  **UNCTAD** فید RSS عمومی معتبری ندارند، بنابراین در نسخه فعلی از
  فهرست خودکار حذف شده‌اند. اگر فید معتبری از این‌ها پیدا کردید،
  می‌توانید در دیکشنری `FEEDS` داخل `main.py` اضافه‌شان کنید.
- برخی فیدها (مثل FT) ممکن است محتوای کامل مقاله را به‌خاطر پولی بودن
  در RSS نگذارند؛ فقط عنوان و خلاصه کوتاه در دسترس است — همان چیزی که
  در پیام تلگرام هم می‌بینید.

## شخصی‌سازی

- تغییر بازه بررسی: متغیر `LOOKBACK_HOURS` در `main.py` (پیش‌فرض ۳ ساعت،
  برای اطمینان از عدم از دست دادن خبر بین اجراها).
- تغییر مدل Gemini: متغیر محیطی `GEMINI_MODEL` در workflow (مثلاً
  `gemini-2.5-flash-lite` برای سهمیه روزانه بیشتر).
- اضافه/حذف منبع: دیکشنری `FEEDS` در ابتدای `main.py`.
- تغییر زمان‌بندی: مقدار `cron` در `.github/workflows/hourly.yml`
  (فرمت آن UTC است، نه ساعت محلی شما).
